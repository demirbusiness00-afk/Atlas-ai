# ATLAS AI V6
Telegram crypto radar.

1D → 4H → 1H → 15M = trend/context
S/R = confirmation
2M = entry timing only

Binance Spot has no native 2m interval, so V6 aggregates consecutive 1m candles.

Railway: deploy as a Worker. Set BOT_TOKEN and SIGNAL_CHAT_ID. No web panel and no trading API keys are required.
Commands: /start /status /diagnostics /top /test
